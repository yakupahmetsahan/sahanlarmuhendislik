Admin Şifresi için Hash Üretici

Yeni şifreni aşağıya yaz, çıkan kodu kopyalayıp phpMyAdmin'de şu sorguyu çalıştır (kod yerine kendi çıkanı koy):

UPDATE admin_users SET password_hash = 'KOD_BURAYA' WHERE username = 'admin';

Hash burada görünecek...

Bu sayfa hiçbir yere veri göndermez, tamamen tarayıcında (bilgisayarında) çalışır — internete ihtiyacı bile yok, dosyayı kaydedip çift tıklayarak açabilirsin.
